# AmneziaWG Panel

پنل مدیریت کاربر برای **AmneziaWG** (فورک مبهم‌سازی‌شده‌ی وایرگارد که در برابر DPI مقاومه) — با یک سرور، بدون نیاز به تانل دوطرفه‌ی جدا، با آمار مصرف دقیق و وضعیت آنلاین لحظه‌ای.

## این پروژه چه مشکلاتی رو حل می‌کنه؟

- ❌ «وایرگارد با یک سرور جواب نمی‌ده» → وایرگارد از اول تک‌سرور و peer-to-peer کار می‌کنه؛ مشکل معمولاً از NAT/forwarding یا کانفیگ اشتباهه. این پروژه NAT، forwarding و MTU رو درست تنظیم می‌کنه.
- ❌ «باید هر چند وقت یک‌بار سرور رو ریبوت کنم» → معمولاً به‌خاطر MTU نامناسب یا نبود `PersistentKeepalive` هست. این‌جا هر دو درست تنظیم شدن.
- ❌ «فیلتر DPI ایران وایرگارد رو می‌شناسه» → به‌جای وایرگارد خام از **AmneziaWG** با پارامترهای مبهم‌سازی تصادفی (Jc/Jmin/Jmax/H1-H4/S1-S2) استفاده می‌شه که امضای قابل‌شناسایی نداره.
- ✅ پنل وب با مدیریت کاربر، مصرف دقیق (bytes real)، وضعیت آنلاین لحظه‌ای (poll هر ۲-۳ ثانیه)، محدودیت حجم و تاریخ انقضا.
- ✅ نصب با یک خط روی اوبونتو، بدون تداخل با سرویس‌های VPN دیگه (اینترفیس و پورت و ساب‌نت اختصاصی).

## نصب سریع

```bash
curl -fsSL https://raw.githubusercontent.com/<YOUR_USERNAME>/amnezia-wg-panel/main/install.sh | sudo bash
```

در حین نصب ازت این‌ها پرسیده می‌شه: آی‌پی/دامنه‌ی سرور، پورت وایرگارد، پورت پنل، نام کاربری و رمز ادمین. در پایان لینک پنل رو بهت نشون می‌ده.

> نکته: اگه اسکریپت رو با `curl | sudo bash` اجرا می‌کنی و می‌خوای سوالات رو جواب بدی، سوالات از `/dev/tty` خونده می‌شن پس مشکلی نیست.

## بعد از نصب

- ورود به پنل: `http://IP_SERVER:PANEL_PORT`
- افزودن کاربر → دانلود فایل کانفیگ یا اسکن QR با اپ WireGuard/AmneziaWG روی گوشی یا کامپیوتر
- مشاهده‌ی مصرف، وضعیت آنلاین، تنظیم سقف حجم و تاریخ انقضا برای هر کاربر

⚠️ کلاینت‌ها باید از اپ **AmneziaWG** (نه وایرگارد معمولی) استفاده کنن چون پارامترهای ضدDPI (Jc, Jmin, Jmax, H1-H4, S1, S2) فقط توسط AmneziaWG پشتیبانی می‌شن. اپ رسمی: https://amnezia.org/downloads

## دستورات مفید

```bash
# وضعیت زنده‌ی تانل
awg show awg0

# لاگ پنل
journalctl -u awg-panel -f

# لاگ تانل
journalctl -u awg-quick@awg0 -f

# ری‌استارت پنل
systemctl restart awg-panel
```

## حذف کامل

```bash
sudo bash uninstall.sh
```

## معماری

```
مرورگر/موبایل کاربر  →  آدمین از طریق پنل وب (FastAPI + SQLite) کاربر می‌سازه
                          │
                          ├─ awg genkey / awg pubkey / awg genpsk   (تولید کلید)
                          ├─ awg set awg0 peer ...                  (اضافه‌کردن زنده، بدون قطعی)
                          ├─ نوشتن در awg0.conf                     (پایداری بعد از ریبوت)
                          └─ awg show awg0 dump  (هر ۲ ثانیه)       (ترافیک + آخرین handshake)

کلاینت (گوشی/کامپیوتر) با اپ AmneziaWG با فایل/QR کانفیگ وصل می‌شه → تانل روی awg0 با پارامترهای مبهم‌سازی
```

## هشدار امنیتی / قانونی
